## 🏥 SIKPU - Sistem Informasi Kunjungan Pasien UKS

Aplikasi berbasis web untuk mencatat dan mengelola kunjungan siswa ke Unit Kesehatan Sekolah (UKS).

## ✨ Fitur Utama
🔐 Sistem Login
Autentikasi menggunakan session
Mendukung password hashing (password_hash)
Proteksi halaman (tidak bisa akses tanpa login)
📊 Dashboard Interaktif
Total Kunjungan
Kunjungan Hari Ini
Kunjungan Bulan Ini
Grafik tren 7 hari (Chart.js)
🧾 Manajemen Data Pasien (CRUD)
Tambah data kunjungan
Edit data
Hapus data
Tampilan tabel responsif
🔍 Pencarian Data
Cari berdasarkan nama atau kelas
Real-time filter
📁 Riwayat Kunjungan
Riwayat per siswa
Total kunjungan per siswa
Edit riwayat lama
📅 Rekap Data
Filter berdasarkan bulan & tahun
Siap untuk laporan
🎨 UI Modern
Sidebar navigation (tanpa header)
Bootstrap 5
Font Awesome icon
## 🛠 Teknologi
Backend: PHP Native (7.2+)
Database: MySQL
Frontend: HTML, CSS, Bootstrap 5
Chart: Chart.js
Security:
Prepared Statement
Session Management
Password Hashing
